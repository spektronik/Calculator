# Calculator (Домашнее задание 1.Консольный калькулятор с плагинами)

Приложение для вычисления математических выражений с поддержкой динамической загрузки плагинов на этапе выполнения.

## Возможности
- Поддержка базовых операций: `+`, `-`, `*`, `/`, `()`
- Динамическая загрузка функций из папки `./plugins` (без перекомпиляции)
- Корректная обработка исключительных ситуаций (деление на ноль, неверный синтаксис, ошибки в плагинах)

## Структура проекта
- `Calculator/` — исходный код основного приложения (парсер, менеджер плагинов)
- `plugins/` — исходный код плагинов (каждый плагин экспортирует ровно одну функцию)
  - `funcsin` — функция синуса (`sin`, принимает градусы)
  - `funcdeg` — функция возведения в степень (`deg`)
  - `funcln` — функция натурального логарифма (`ln`)
